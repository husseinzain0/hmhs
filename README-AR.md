# بناء تطبيق HMH System (APK)

1. أنشئ حساباً مجانياً في github.com ثم مستودعاً جديداً (New repository).
2. ارفع كل محتويات هذا المجلد إليه (Add file ← Upload files)، مع مجلد `.github` المخفي.
   إن لم يظهر المجلد المخفي في جهازك فأنشئ الملف يدوياً: `.github/workflows/build-apk.yml` وانسخ محتواه.
3. افتح تبويب Actions ← "Build APK" ← انتظر 3–6 دقائق حتى يظهر ✔.
4. من أسفل صفحة التشغيل نزّل الملف المضغوط `HMH-System-APK` ثم فك الضغط واحصل على `app-debug.apk`.
5. انقله إلى الهاتف وافتحه (اسمح بـ«التثبيت من مصادر غير معروفة» لتطبيق الملفات أو المتصفح).

ملاحظات: التطبيق موقَّع بمفتاح debug (صالح للاستخدام الشخصي). الاتصال بالخوادم عبر HTTPS فقط.
